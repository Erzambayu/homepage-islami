# 🕌 Homepage Islami

Homepage personal dengan tema Islami modern. Dilengkapi dengan jadwal sholat otomatis, ayat Al-Quran harian dengan audio murottal, widget cuaca, tasbih digital, dan berbagai fitur inspiratif lainnya.

![Homepage Islami Preview](https://img.shields.io/badge/Status-Active-brightgreen) ![License](https://img.shields.io/badge/License-MIT-blue)

## ✨ Fitur

- 🕐 **Jadwal Sholat Otomatis** - Berdasarkan lokasi (Jakarta default)
- ⏱️ **Countdown Waktu Sholat** - Hitung mundur menuju waktu sholat berikutnya
- 📖 **Ayat Al-Quran Harian** - Random ayat dengan terjemahan Indonesia
- 🎧 **Audio Murottal** - Dengarkan tilawah dari Qari Mishary Rashid Alafasy
- 🌤️ **Widget Cuaca** - Cuaca real-time berdasarkan lokasi Anda
- 📿 **Tasbih Digital** - Counter dzikir dengan penyimpanan lokal
- 🤲 **Doa Harian** - Kumpulan doa sehari-hari
- 💡 **Inspirasi Sunnah** - Tips amalan sunnah harian
- 💬 **Quote Islami** - Motivasi dan nasihat harian
- 🌙 **Dark Mode** - Mode gelap untuk kenyamanan mata
- 📅 **Tanggal Hijriyah** - Tampilan tanggal Islam
- 🌅 **Background Dinamis** - Berubah sesuai waktu (pagi/siang/sore/malam)
- 🔍 **Google Search** - Pencarian cepat terintegrasi

## 🚀 Demo

Buka file `index.html` di browser Anda atau kunjungi:
[Homepage Islami Live](https://erzambayu.github.io/homepage-islami)

## 📦 Instalasi

1. Clone repository ini:
```bash
git clone https://github.com/Erzambayu/homepage-islami.git
```

2. Buka folder project:
```bash
cd homepage-islami
```

3. Buka `index.html` di browser favorit Anda

## 🛠️ Teknologi

- HTML5
- CSS3 (Glassmorphism, CSS Variables)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Poppins, Amiri)

## 📡 API yang Digunakan

| API | Kegunaan |
|-----|----------|
| [Aladhan API](https://aladhan.com/prayer-times-api) | Jadwal Sholat |
| [Al-Quran Cloud](https://alquran.cloud/api) | Ayat Al-Quran |
| [Islamic Network CDN](https://cdn.islamic.network) | Audio Murottal |
| [Open-Meteo](https://open-meteo.com) | Data Cuaca |
| [Nominatim OSM](https://nominatim.openstreetmap.org) | Geocoding |
